# SecureCRT 批量取数 Excel 汇总工具 — 设计文档

日期：2026-08-26
状态：已与用户逐节确认

## 1. 背景与目标

运维人员需要在装有 SecureCRT 的机器上批量登录服务器执行查询指令，把各台设备的输出解析后汇总成 Excel 表格。

关键约束：

- **只有特定机器（装有 SecureCRT）能访问目标服务器，开发机无法访问**。因此工具必须跑在 SecureCRT 机器上，开发机只能通过"模拟模式"验证全流程。
- 目标机器 SecureCRT 版本不确定 → 取数引擎用 **VBScript 脚本接口**（所有 SecureCRT 版本均支持）。
- 主程序打包为**免安装 exe**，目标机器不需要装 Python、不需要装 Office（Excel 由 openpyxl 直接生成）。
- 目标设备为华为 VRP 设备（样例：`disp alarm hardware` 输出）。

## 2. 总体架构

两个组件，通过任务文件交互：

```
[主程序 exe]  Python/Tkinter，PyInstaller 打包
   │ ① 用户填服务器清单 + 查询指令 + 保存路径 + 并发数
   │ ② 每台生成任务文件 task/<IP>.txt（账号、密码、指令、超时）
   │ ③ 按并发数分批，每台启动一个 SecureCRT.exe /SCRIPT engine.vbs /ARG task/<IP>.txt
   ▼
[engine.vbs × N]  每个进程只处理一台服务器
   │ ④ SSH2 连接 → 关分页 → 发指令 → 捕获输出 → 断开 → 退出
   │ ⑤ 结果写入 results/<IP>_raw.txt + results/<IP>_status.txt
   ▼
[主程序 exe]  ⑥ 等待全部子进程退出 → 读结果 → 解析 → 生成 Excel
```

- **并发执行**：并发数界面可配（默认 5，范围 1-10）。每台服务器一个独立 SecureCRT 进程，互不阻塞：一台 IP 不可达挂起时其他照常跑，总耗时约 `N ÷ 并发数 × 单台耗时`。
- **并发影响（已在界面提示）**：运行期间桌面会弹出多个 SecureCRT 窗口，用户不能手动操作这些窗口；每进程约占几十 MB 内存。
- **停止按钮**：写 stop.flag 标志文件，未开始的机器不再启动并记为"已停止"；已在跑的机器等其自然结束（受单台超时上限约束）。不杀进程——SecureCRT 默认单实例，杀进程会连同用户自己的 SecureCRT 窗口一起关掉。完成判定以各台状态文件为准（兼容单实例复用）。
- SecureCRT.exe 路径自动从注册表/常见安装路径检测，检测不到则用户手动指定。
- 任务文件 task/<IP>.txt 为明文（含密码），放在程序运行目录下，仅本机使用；运行结束后自动清理（保留 results 供排障）；后续版本可考虑加密。

## 3. 界面设计（中文）

从上到下：

1. **SecureCRT.exe 路径选择行**：自动检测 + 可浏览指定。
2. **Excel 保存位置行**：完整文件路径输入框（含 .xlsx 文件名）+ 浏览按钮（"另存为"式对话框，默认建议名 `SecureCRT巡检结果_YYYYMMDD_HHMMSS.xlsx`）；记住上次使用的位置（存入 config.json）；完成后自动保存到该路径，文件已存在时提示是否覆盖。
3. **服务器清单表格**：列 = IP | 主机名 | 账号 | 密码；可逐行编辑；支持"导入 iplist.txt"（按空格分隔解析，格式同样例：`IP 主机名 账号 密码`）和"粘贴多行批量添加"；可删除选中行。
4. **指令区**：查询指令输入框 + 每台超时秒数（默认 60）。
5. **并发数**：数字输入框（默认 5，范围 1-10）。
6. **模拟模式勾选框**：勾选后不调用 SecureCRT，用内置样例输出走完解析和 Excel 生成全流程。
7. **运行区**：开始/停止按钮、进度条、运行日志框、每台执行状态列表。开始前校验：清单非空、指令非空、Excel 保存路径有效、SecureCRT 路径有效（模拟模式不校验 SecureCRT）。
8. 界面配置（清单、指令、路径）自动保存到本地 config.json，下次打开自动恢复。

## 4. 取数引擎（engine.vbs）

### 4.1 每台服务器的取数流程（每个进程一台，参数由主程序通过 /ARG 传入）

1. 从 `/ARG` 指定的任务文件读入 IP、主机名、账号、密码、超时秒数、查询指令、结果前缀、停止标志路径（任务文件为 UTF-8、每行一个字段、共 8 行，避免密码出现在进程命令行）。
2. 检查停止标志文件，存在则写 STOPPED 状态退出。
3. `Connect("/SSH2 /ACCEPTHOSTKEYS /L <账号> /PASSWORD <密码> <IP>")` 建立连接，连接异常写 FAIL。
4. 等待设备命令提示符（华为格式 `<主机名>`，等 `<` 字符，超时 30 秒）。
5. 发送 `screen-length 0 temporary` 关闭分页（临时生效，不改设备配置），等提示符回来。
6. 发送查询指令，用 `Screen.ReadString` 以**字面量提示符 `<主机名>`（取自任务文件）**捕获整段输出到 `results/<IP>_raw.txt`——不用正则，避免输出中的 `<...>` 内容提前截断捕获；捕获异常/超时写 FAIL。
7. 写入 `results/<IP>_status.txt`（状态、失败原因），断开连接，退出进程。
8. 脚本全程容错（`On Error Resume Next`）：任何脚本运行时错误都降级为 FAIL 状态，保证主程序状态轮询总能收敛。

### 4.2 失败场景处理（各台独立记录，失败不影响其他机器）

| 场景 | 判定方式 | 记录 |
|------|---------|------|
| 连接失败/密码错误 | 连接后 30 秒内未出现提示符（含认证失败提示） | 失败 + 原因 |
| 指令执行超时 | 发指令后超过设定秒数未回到提示符 | 失败 + 原因 |
| 输出为空 | 捕获文本无有效内容 | 失败 + 原因 |
| 正常 | 捕获到输出 | 成功 |

### 4.3 任务文件格式

- `task/<IP>.txt`：UTF-8、每行一个字段、共 9 行：`IP / 主机名 / 账号 / 密码 / 超时秒数 / 查询指令 / 结果文件前缀(绝对路径) / 停止标志文件(绝对路径) / run_id`（密码允许含 `!` 等特殊字符；run_id 为每次运行的唯一标识，用于防止上一轮遗留引擎的迟到状态污染新一轮结果）。
- `results/<IP>_status.txt`：每台 `IP<TAB>状态<TAB>失败原因<TAB>run_id`（各进程独立写各自文件，避免写冲突；主程序忽略 run_id 不匹配的状态）。
- `results/<IP>_raw.txt`：每台原始输出（引擎 ADODB.Stream 写入的 UTF-8 含 BOM，主程序用 utf-8-sig 读取）。

### 4.4 已知限制

- SecureCRT 脚本接口对"IP 不可达"的 TCP 连接挂起时间取决于 SecureCRT 全局连接超时设置（默认约 1 分钟）；如需更短可在 SecureCRT 全局选项里调小。设计文档如实说明，不做绕行。

## 5. 输出解析与 Excel 生成

### 5.1 解析规则（固定格式，以华为 `disp alarm hardware` 为例）

- 去除 `----` 分隔线和表头行（`Index Level Date Time Info`）。
- 识别告警行：行首 `序号 + 级别(Critical/Major/Minor/Warning) + 日期 + 时间`。
- 折行处理：过长 Info 被折到下一行（行首大量空格），自动拼回上一行的 Info 字段。
- 清除任何残留的 `---- More ----` 分页标记（兜底：正常情况下 `screen-length 0 temporary` 已保证不出现分页）。

### 5.2 Excel 输出（两个 sheet）

- **明细表**：IP、主机名、告警序号、级别、日期、时间、告警内容。
- **汇总表**：IP、主机名、状态（成功/失败）、失败原因、告警总数、Critical、Major、Minor、Warning 各级计数。

## 6. 模拟模式（开发/验证关键能力）

- 界面勾选"模拟取数（测试用）"：不调用 SecureCRT，直接用内置样例输出（含 iplist.txt 样例及折行、多告警、空输出等边界样例）走完 解析 → Excel 全流程。
- 用途：① 开发机上验证全链路；② 用户拿到目标机器前先试用确认表格效果。
- 真实模式下 SecureCRT 未安装/路径错误时给出明确报错。

## 7. 测试策略

- 解析器单元测试：正常样例、折行、多告警、空输出、异常格式。
- 模拟模式端到端测试（开发机可做）。
- 并发测试：模拟模式下验证分批调度、全部完成/中途停止、混合成功失败时的汇总正确性。
- 真实环境验证：交付后由用户在目标机器跑真实设备，附验证清单（含：正常取数、密码错误、IP 不可达、超时、多台并发混合成功失败、并发时内存占用）。

## 8. 范围外（YAGNI）

- 多指令/每台独立指令
- 密码加密存储
- 用户自定义解析规则
- 增量告警对比、历史归档
